The file generated by above code is a bit messy and can be cleaned afterwards with grep.  Downside is that this provides email only and will remove the display name if it exists in the data.  After running below it is worthwhile doing a duplicate removal (duplicate removal on python code takes place on the entire to email line, not the raw addresses):

grep -E -o "\b[A-Za-z0-9._%+-]+@[A-Za-z0-9.-]+\.[A-Za-z]{2,6}\b"
infile.txt > outfile.txt
